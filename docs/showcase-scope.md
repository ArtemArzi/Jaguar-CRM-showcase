# Состав публичной копии

Копия подготовлена 19 сентября 2026 года для просмотра исходников работодателем. История внутренней разработки не переносилась.

Включены backend/frontend, миграции, статические ресурсы, локальные зависимости, доменные тесты и Playwright-сценарии. Админский CSS сохранён как runtime-ресурс.

Исключены внутренние рабочие документы, сведения об эксплуатации, CI/release-конфигурация, закрытые данные, реальные доступы и старый персонализированный demo-helper `seed_p0_payment_ux_demo`. Проверки, относящиеся только к исключённой инфраструктуре, также не перенесены: `test_deploy_hardening_static.py`, `test_release_pipeline.py`, `test_release_local.py`, `test_ci_workflows.py`.

Имена в `seed_trainer_testdata` заменены явно синтетическими; номера остались последовательными тестовыми значениями. Сохранены проверки этой команды. Из npm scripts убраны команды публикации внутренних релизов. Два локальных real-stack E2E runner сохранены вместе с тестами и проверками изоляции базы.

Остальной прикладной код перенесён без функциональных изменений. Эти изменения описывают упаковку публичной копии, а не новый релиз CRM.
