# Сценарии и материалы для оценки CRM

## Пройти продукт без установки

1. Откройте [кейс](https://artemarzi.github.io/portfolio/projects/#crm).
2. Посмотрите desktop-админку, интерфейсы тренера, ученика и родителя, киоск.
3. В [галерее](https://artemarzi.github.io/portfolio/jaguar-crm/) откройте экран в полном размере или скачайте ZIP.
4. Данные на скриншотах вымышленные; доступность оплаты относится к демо-стенду.

## Прочитать код по конкретному вопросу

| Вопрос | Источник |
| --- | --- |
| Как разделяются клубы и права? | `apps/clubs/`, `for_club`, tenant-negative E2E |
| Как связаны расписание и посещение? | `apps/attendance/`, checkin-lifecycle E2E |
| Как работают абонементы и оплата? | `apps/billing/`, тесты модуля |
| Где банковский провайдер? | `apps/billing/payment_providers/tochka.py` |
| Где мобильные роли? | `frontend/src/` |
| Где сценарии интерфейсов? | `frontend/e2e/` |

## Результат и границы

CRM — рабочий продукт с поэтапным внедрением. Есть несколько интерфейсов и банковская интеграция; реальные платежи в демонстрации отключены. Возможность дальнейшего развития не означает личного обязательства автора продолжать этот проект после трудоустройства.

Демонстрационные суммы, списки и показатели не являются доказательством выручки, экономии времени или числа реальных клиентов. Исходники показывают состояние публичного среза; крупные модули остаются кандидатами на рефакторинг.

Документация расширена 30.09.2026. Код и зависимости исходного публичного среза не обновлялись; исходная проверка описана отдельно в `showcase-scope.md`.
